# yding25.github.io

Personal homepage for [Yan Ding](https://yding25.com), published from `main` by GitHub Pages.

## Publications

Publication records live in `data/publications.json` and are mirrored in the `publicationDataJson` block in `index.html` so the static page also works without a data request. Keep both copies identical when editing records. Records are grouped by year and filtered by category.

- Categories: `data-pipelines`, `embodied-models`, and `deployment`.
- `image` may be empty for manuscripts without a public figure.
- Optional `role` displays the homepage owner's contribution role.
- Optional `award` names the workshop and year associated with a Best Paper Award.
- An unpublished manuscript may have an empty `links` array. Do not add private manuscript or Overleaf links.

The October 2026 update adds the VAP-TAMP workshop award and recent publications. AWARE-VLA's title, anonymous author status, corresponding-author role, and ICRA 2026 submission venue are supplied by Yan Ding; no public manuscript is linked.
